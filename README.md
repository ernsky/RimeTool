# RimeTool 使用指南（小白版）

> 本指南面向第一次使用 RimeTool 的人。你不需要懂编程，只要跟着「点哪里、做什么」一步步来就行。
> 文中凡是带「➜」的都是**操作步骤**；带「💡」的是**省钱省时间的提示**。

---

## 一、RimeTool 是干嘛的？

RimeTool 是一个「五笔词库编辑器」。简单说：

- Rime 是电脑上的输入法引擎，它的词库就是一个个大表格（词组 / 编码 / 词频 / 分组 / 启用）。
- RimeTool 让你**像用 Excel 一样**查看、增删、改、筛选这些词，还能一键把改好的词**导出回 Rime**、触发部署生效。
- 它还顺手帮你做几件麻烦事：查重复词、按字数筛词、语音朗读稿里找出「读得出来但词库没有」的词、批量改权重等。

一句话：**想动 Rime 五笔词库，用这个工具最省事。**

---

## 二、第一次怎么打开它

有三种打开方式，挑你手头有的：

| 你手头有 | 怎么打开 |
|---|---|
| 已经打包好的 `RimeTool.exe` | 双击 `RimeTool.exe`（在 `D:\Documents\Downloads\Temp\RimeTool\RimeTool\` 下） |
| 一整套源码（`main.py` 等） | 双击 `启动词库工具.vbs`（无黑窗口）；或命令行 `python main.py` |
| 只是想重新打包 | 双击 `打包exe.bat`（见文末附录） |

➜ 第一次打开时，如果提示要配置，先点顶栏的 **「配置」** 按钮，把「TSV 词库文件」和「Rime 配置文件夹」指好（详见第六节）。

💡 程序右上角/任务栏的蓝色图标就是它。如果图标是空白方块，说明 `resources/app_icon.ico` 丢了——不影响使用，只是没图标。

## 三、界面长什么样（先认路）

打开后，窗口从上到下、从左到右分成几块，记住它们的「位置名」以后沟通最准：

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：配置 | 部署 | 保存  [词组][编码][词频][分组][启用] 搜索 删除 ⇄交换权重│
├──────────┬───────────┬──────────────────────┬────────────────┤
│ 目录树   │ 分组面板  │   中间大表格（5 列）  │  右侧功能栏    │
│ fileTree │ groupList │   词组/编码/词频/分组/启用         │  (11 个按钮) │
├──────────┴───────────┴──────────────────────┴────────────────┤
│ 状态栏：显示行数 / 当前词库名 / 操作提示                      │
└──────────────────────────────────────────────────────────────┘
```

- **顶栏**：放「配置 / 部署 / 保存」三个主按钮、五个输入框（五框）、「搜索 / 删除 / ⇄交换权重」。
- **左目录树**：你的词库文件列表（点一下切换打开哪个词库）。
- **左分组面板**：按「分组」列出的清单，可以**把词直接拖进来换分组**。
- **中间大表格**：词库本体，5 列。百万行也不卡（会自动分批加载）。
- **右侧功能栏**：11 个功能按钮，本文重点。
- **状态栏**：最底下那行灰字，告诉你现在加载了多少行、在干什么。

💡 四块之间那道细细的分隔线是「分隔条」，可以用鼠标拖动改变各块宽窄。

## 四、顶栏：每个按钮怎么用

顶栏从左到右依次是：

### 1. 配置
打开「配置对话框」。在这里告诉程序：
- **TSV 词库文件**（你的主词库 `.tsv` 在哪）
- **Rime 配置文件夹**（导出去哪、部署触发哪）
- **外观**（自动 / 浅色 / 深色）
- **语音文件 / 输出文件夹 / 单字编码文件**
- 还有「**从备份恢复**」入口（详见第七节）

➜ 第一次用，先点它把词库路径指好，然后点「保存配置」。

### 2. 部署
「保存并请求 Rime 部署」。**点它会把你当前的改动先保存，再通知 Rime 重新加载词库**。
💡 平时改完词，点一次「部署」就齐活了（等价于先点保存再导出）。

### 3. 保存
「录入提交 / 保存」。**把你在五框里改的内容写回 TSV 文件**。
- 五框都填全 → 写入：选中了某行就改那行，没选中就新增一行；多选则批量改分组/启用。
- 五框缺了某个要素 → 自动弹「五笔编码」窗口帮你补全再落盘。
💡 所有改动**只有点了保存/部署才会真正写进文件**，关窗口前记得存。

### 4. 五个输入框（五框）：词组 / 编码 / 词频 / 分组 / 启用
这是「筛选 + 录入」的联合入口，互相联动：
- 在任意一框里打字或选值 → 中间表格会**只显示匹配的行**。
- 结果**只有一行**时，会自动把那行的五个字段回填到五框，方便你直接改。
- 改完想落盘 → 点「保存」。

💡 举例：在「词组」框输入「中国」，表格就只留含「中国」的词；在「分组」下拉选 `B 青云`，就只看这个分组的词。

### 5. 搜索
按五框当前条件**筛选**中间列表（词组/编码/词频做子串匹配，编码不区分大小写）。
💡 其实你边在五框打字边就实时筛选了；「搜索」相当于「确认/重新应用」一下。

### 6. 删除
**删除选中的行**（可多选：Ctrl 或 Shift 点选）。
- 删除前会弹确认框（防误删）。
- 删除只是改内存，**点保存才真正从文件删掉**。

### 7. ⇄交换权重
**选中恰好 2 行**，点它 → 这俩词的「词频（权重）」互换。
💡 想调两个词的优先顺序又不想手填数字时特别好用。只选 2 行才亮，选多了/少了都是灰的。

## 五、中间表格怎么用

- **点一行** = 选中，五框会显示它的内容。
- **Ctrl+点 / Shift+点** = 多选。
- **拖拽行**：按住选中行往上/往下拖，可调整组内顺序（松手即生效，保存后落盘）。
- **列头排序**：点列头可按该列排（词频列按数字大小排）。
- 表格最左边那列是「分组头行」（如 `A 青云`），纯分组标题，不可编辑。

## 六、右侧功能栏：11 个按钮逐个说

右侧栏从上到下的按钮（其中第 5 项是 6 个小按钮排成一行）：

### ① ➕ 新建编码
弹出「五笔编码」窗口，批量新增词条。
➜ 步骤：点它 → 每行输入一个词组 → 选一种编码规则 → 选目标分组/启用/词频 → 「预览」看 `词组→编码` → 「生成并追加到词库」。
💡 编码规则有 6 种（标准、逐字、前两后一、全两码、自由、五笔拼音），不会自动猜，要自己选。自由编码只能单行、只收小写字母+空格。

### ② 📤 导出到Rime
把当前 TSV 里**启用码为 `A`** 的词，按分组首字母（A–F）分发写回对应的 Rime 词典，并触发部署。
💡 写之前会自动备份目标词典（见第七节），放心点。只有 `A` 才导出，其他启用码（如 `Y`/`D`）不导出。

### ③ ✏️ 批量修改TSV权重
按参考码表**重算并覆盖**整张表的词频权重，缺失的词条会自动新增（默认进 `A 备用` 分组、启用 `A`）。
💡 写前自动备份主 TSV；**不触发部署**（只改权重，不碰 Rime）。

### ④ 🎙️ 语音词组查漏
对比「语音朗读稿」和你的词库，找出**语音里有、但词库缺**的词组，结果写进输出文件夹。
💡 需要 `jieba` 分词库；没装的话点它会报错退出（不影响别的按钮）。配置里要指好「语音文件」和「输出文件夹」。

### ⑤ 字数筛选（无 / 一 / 二 / 三 / 四 / 多）
一排 6 个小按钮，按「词组长度」筛：
- `无` = 关掉此筛选（显示全部）
- `一~四` = 只显示 1~4 个字的词
- `多` = 只显示 ≥5 个字的词
💡 和别的条件**叠加**（AND）：比如同时选「分组=A 青云」+「二」，就只看青云组里的两字词。

### ⑥ 🔢 一词多码（可开关）
点一下变蓝（开）→ 只显示「同一个词组有多个不同编码」的行。再点一下关掉。
💡 用来排查「一个词被编了好几个码」的情况。

### ⑦ 💾 保存为单一码表
把启用=`A` 的行按分组首字母拆开导出：以 `E` 开头的 → `English.dict.yaml`，其他 → `wubi.dict.yaml`（会弹窗让你选保存位置）。
💡 跟「导出到Rime」不同：这个是导出成**独立码表文件**，不直接写 Rime。

### ⑧ ⚠ 要素不全（可开关）
点一下变蓝（开）→ 只显示「五个要素（词组/编码/词频/分组/启用）有任意一项为空」的行。再点关掉。
💡 用来**体检**：一眼找出没填全、导出会漏掉的词条。

### ⑨ 👁 高亮重复（可开关）
点一下变蓝（开）→ 把「(词组,编码) 相同的重复词」用琥珀色底标出来（不删，只标）。再点关掉。
💡 百万行也只是重画底色，不卡。

### ⑩ ⏭ 下一处重复
配合「高亮重复」用：从当前选中行往后找**下一个重复词**并滚到它；到末尾会循环回顶部。
💡 逐处检查重复时，一直点它就逐个跳。

### ⑪ 🔀 合并重复
把重复词合并：保留每组**第一次出现**的那行，其余删除，词频取「最高」或「相加」（弹窗里选）。
💡 合并是**破坏性**操作，但写文件前会备份，且只动内存，点「保存」才落盘。

## 七、拖拽：两种最顺手的操作

RimeTool 把两个常用动作做成了「拖」：

### 拖到左侧分组面板 = 换分组
➜ 在中间表格**选中一行或多行** → 拖到左侧「分组面板」里某个分组项上松手 → 这些词就归到那个分组了（默认同时把启用码设为 `A`）。
💡 比早期「移动到分组」按钮更直观，原按钮已移除。

### 表格内拖行 = 调顺序
➜ 在中间表格按住选中行，上下拖动到目标位置松手 → 组内顺序即调整（保存后落盘）。

## 八、常见场景：照着做

### 场景 A：新增一个词
1. 顶栏五框里把「词组/编码/词频/分组/启用」填全。
2. 点「**保存**」→ 新词写入。
💡 嫌手填编码麻烦？点右侧「**➕ 新建编码**」，让它按规则帮你算码。

### 场景 B：把一个词换个分组
1. 中间表格选中那个词。
2. 拖到左侧分组面板的「目标分组」上松手。
3. 点「**保存**」。

### 场景 C：找出并清理重复词
1. 右侧点「**👁 高亮重复**」→ 重复的都标色。
2. 慢慢看，或点「**⏭ 下一处重复**」逐个跳。
3. 确认要合并 → 点「**🔀 合并重复**」→ 选「最高/相加」→ 确定。
4. 点「**保存**」。

### 场景 D：把改好的词库推到 Rime
1. 确认要导出的词「启用」列都是 `A`。
2. 点右侧「**📤 导出到Rime**」。
3. 它会自动分发+触发部署。也可直接点顶栏「**部署**」。

### 场景 E：只改权重不碰 Rime
1. 点右侧「**✏️ 批量修改TSV权重**」。
2. 它按参考码表重算整表权重并写回 TSV（自动备份）。
3. 若要生效到 Rime，再点「导出到Rime」或「部署」。

### 场景 F：语音读稿找漏词
1. 「配置」里指好「语音文件」(SayIt JSON) 和「输出文件夹」。
2. 点右侧「**🎙️ 语音词组查漏**」→ 结果清单写到输出文件夹。
3. 拿清单去「➕ 新建编码」补词。

## 九、保存、备份与恢复（重要！）

- **改了不保存 = 白改**：关窗口/导出前，记得点「保存」或「部署」。关窗口若检测到未保存，会提醒你。
- **自动备份**：凡是写回源文件（保存、导出、批量改权重、合并…）前，程序都会通过 `core/backup.py` 在 `RimeTool/Logs/` 下生成一份 `.bak.gz` 快照。
- **怎么恢复**：顶栏点「**配置**」→ 里面「**从备份恢复**」子模块，挑一份快照还原即可。
💡 源文件旁边**不会**冒出一堆 `.bak` 散文件，备份都集中在 `Logs/` 里，干净。

## 十、外观与主题

- 「配置」里「外观」可选：**自动**（跟系统）/ **浅色** / **深色**。
- 改完即时生效，连 Windows 原生标题栏都会跟着切深色。
- 配色是**蓝/灰**风格：浅色以蓝 `#1e3a8a` 为主、灰白底；深色冷灰蓝 `#5c7fb8`、近黑底。选中行是蓝色半透明。

## 十一、小白最常问

- **Q：我改完关了窗口，词没变？** → 你没点「保存/部署」。改动只在内存，必须保存才写文件。
- **Q：导出后 Rime 没变化？** → 检查那些词的「启用」是不是 `A`；只有 `A` 才导出。再点一次「部署」触发重载。
- **Q：按钮是灰的、点不动？** → 多半是「没选中行」或「选的行数不对」（如交换权重要恰好 2 行），或当前是只读的 dict 预览模式（3 列，很多功能禁用）。
- **Q：拖不动分组？** → 确认选了中间表格的行，再拖到左侧分组面板的具体分组项上。
- **Q：点「语音查漏」报错？** → 没装 `jieba` 分词库，或配置里语音文件路径没指对。
- **Q：能不能 Ctrl+F 查找替换？** → 当前版本的「查找/替换」对话框尚未接线到主窗口，用顶部五框筛选 + 选中行编辑来替代。

## 附录：一键打包成 exe

若你拿到的是源码、想自己打成可双击的 `RimeTool.exe`：

➜ 双击根目录的 **`打包exe.bat`**（在普通 Windows 终端里跑，不要在沙箱终端跑）。
➜ 完成后产物在 `D:\Documents\Downloads\Temp\RimeTool\RimeTool\`，里面有 `RimeTool.exe` 和 `_internal/` 文件夹，**两个要放在一起**才能运行。
